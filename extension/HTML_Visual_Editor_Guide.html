🎨 HTML Visual Editor

Kiro 專用 HTML 視覺編輯工具

📖 簡介

HTML Visual Editor 是一個為 Kiro 開發工具設計的擴充功能，提供即時的 HTML 代碼編輯和預覽功能。左邊編輯 HTML，右邊立即看到渲染結果，大大提升開發效率。

📦 版本 0.1.0
🛠️ 支持工具 Kiro（VS Code 衍生版）
📍 安裝位置 ~/.kiro/extensions/

✨ 核心功能

📝

代碼編輯

左側全功能 HTML 編輯器，支持語法高亮和自動縮進

👁️

實時預覽

右側即時顯示 HTML 渲染結果，邊改邊看

💾

自動保存

Ctrl+S 快速保存，支持撤銷/重做

🚀

高效開發

分割視圖設計，邊編輯邊預覽，零延遲

🚀 快速開始

1

打開 Kiro

啟動 Kiro 開發工具

2

創建或打開 HTML 檔案

新建 .html 檔案或打開現有的

3

右鍵選擇編輯器

右鍵點擊檔案 → 選擇「HTML Visual Editor」

4

開始編輯

左邊編輯代碼，右邊實時預覽結果

⌨️ 快捷鍵

保存檔案 Ctrl + S
撤銷 Ctrl + Z
重做 Ctrl + Y

❓ 常見問題

Q: 預覽窗口沒有顯示？

A: 請確保：

  • Kiro 已完全重啟
  • extension 正確安裝在 ~/.kiro/extensions/ 目錄
  • HTML 檔案語法正確

Q: 保存後檔案沒有更新？

A: 嘗試：

  • 確認按下 Ctrl+S
  • 檢查編輯器右上角是否有「修改」指示符
  • 查看 Kiro 的輸出日誌

Q: 如何卸載 extension？

A: 在 Kiro 擴充功能面板搜尋「html-visual-editor」，點擊卸載即可。
