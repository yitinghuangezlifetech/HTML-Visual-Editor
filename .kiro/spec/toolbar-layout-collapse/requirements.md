# 需求：工具列版面調整與收合（toolbar-layout-collapse）

## 背景

目前右側面板由上而下堆疊四條工具列（面板標題列、表格列、區塊列、Quill 文字工具列），
垂直空間被大量佔用，實際可編輯區域偏小。
同時「儲存」與「收闔原始碼」兩個常用按鈕位於最上方的全域 topbar，
與使用者實際操作焦點（右側編輯／預覽面板）距離較遠。

## 使用者故事

- 身為**內容編輯者**，我希望「儲存」與「收闔原始碼」按鈕出現在右側面板 `👁 Preview` 按鈕的右方，
  以便在編輯區附近就能直接存檔與切換版面，不必移動到畫面最上方。
- 身為**內容編輯者**，我希望「表格」與「區塊」兩組按鈕合併在同一行，並有一個按鈕可一鍵收合，
  以便不使用表格／區塊功能時把垂直空間讓給編輯區。
- 身為**內容編輯者**，我希望文字編輯工具列（Quill toolbar）也有收合按鈕，
  以便專注在內容撰寫時獲得更大的編輯區域。

## 驗收條件

### A. 按鈕移至 Preview 右方
- [ ] A1. `💾 Save` 按鈕顯示於右側面板標題列，位於 `👁 Preview` 按鈕右方。
- [ ] A2. `◀ 收闔原始碼` 按鈕顯示於右側面板標題列，位於 `💾 Save` 右方。
- [ ] A3. 兩顆按鈕原本在 topbar 的位置移除，topbar 僅保留標題與狀態訊息。
- [ ] A4. 兩顆按鈕功能不變：Save 觸發存檔並同步 `.md`；收闔原始碼切換左側面板顯示／隱藏，且按鈕文字在
       `◀ 收闔原始碼` / `▶ 展開原始碼` 間切換。
- [ ] A5. `Ctrl+S` 快捷鍵行為不變。
- [ ] A6. 左側面板收闔時，這兩顆按鈕仍可見可用（因位於右側面板）。

### B. 表格列與區塊列合併為單行 + 收合
- [ ] B1. 「表格:」與「區塊:」兩組按鈕合併顯示於同一行工具列。
- [ ] B2. 該行最左（或最右）提供一顆收合按鈕，點擊後整行按鈕隱藏，再點擊則展開。
- [ ] B3. 收合狀態下按鈕以可辨識的箭頭／圖示表示目前狀態（展開 ▾ / 收合 ▸）。
- [ ] B4. 合併後所有既有按鈕與元素 ID 保留可用：`tblInsert`、`tblRowAbove`、`tblRowBelow`、
       `tblColLeft`、`tblColRight`、`tblDelRow`、`tblDelCol`、`tblDelTable`、`tablePopover`、
       `tblRows`、`tblCols`、`tblConfirm`、`tblCancel`、`blkInsert`、`blkBgColor`、`blkBgClear`。
- [ ] B5. 插入表格的內嵌彈窗（`#tablePopover`）在合併後仍能正確定位顯示於該行下方。
- [ ] B6. 面板寬度較窄時，該行按鈕可換行或水平捲動，不得遮蔽或溢出破版。

### C. 文字編輯工具列收合
- [ ] C1. Quill 文字工具列（`.ql-toolbar`）提供一顆收合按鈕。
- [ ] C2. 點擊後隱藏整條 Quill 工具列，編輯區隨之向上擴張；再點擊則還原。
- [ ] C3. 收合／展開不影響 Quill 編輯器狀態（內容、游標、undo 歷史不得重置）。

### D. 共通
- [ ] D1. 收合狀態在單次編輯器開啟期間保持；切換 `🖊 Rich` / `👁 Preview` 模式後回到 Rich 時狀態不重置。
- [ ] D2. 不破壞 Webview 三大鐵則（CSP 含 `${webview.cspSource}`、`acquireVsCodeApi()` 僅呼叫一次、
       HTML 提供 bundle 依賴的所有元素 ID）。
- [ ] D3. `npm run build` 通過，既有 jest 測試全數通過。
- [ ] D4. 手動煙霧測試通過（`.kiro/steering/basic.md` Section 2 清單）。

## 已確認決議（2026-09-19 使用者確認）

1. **`轉存html` 按鈕**（`#exportHtmlBtn`，目前預設隱藏）：**一併移到右側面板標題列**，與 Save、收闔原始碼相鄰
   （顯示／隱藏條件不變）。
2. **收合狀態需持久化**：三組收合狀態（原始碼面板、表格＋區塊列、Quill 文字工具列）以 webview state
   保存，關閉檔案再開啟仍維持上次狀態。
   → 因此 **D1 升級為**：收合狀態跨 webview 重載／重開檔案皆保持。

## 範圍外（Out of Scope）

- 不調整左側原始碼面板的既有按鈕（搜尋、字體縮放、30/50/70 寬度）。
- 不新增任何表格／區塊／文字編輯的**功能**，僅調整版面與收合。
- 不變更 postMessage 通訊協定。
- 不處理主題／配色切換。
