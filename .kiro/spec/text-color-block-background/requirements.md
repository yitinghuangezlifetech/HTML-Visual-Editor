# 需求：文字顏色編輯與區塊底色

## 背景

目前 Quill 工具列（`rich-editor.ts` 第112行）已內建「顏色」與「背景色」下拉選單，但尚未確認是否與左側原始碼（`sourceArea`）正確雙向同步、是否支援自訂色碼、以及儲存/預覽是否正確渲染。此外，目前沒有「插入區塊容器並設定底色」的功能。

本需求涵蓋兩個子功能：
1. 文字顏色編輯（確認並強化現有功能）
2. 建立區塊並設定底色（新功能）

---

## 子功能 1：文字顏色編輯（確認並強化現有功能）

### 使用者故事
- 身為內容編輯者，我希望選取文字後能設定文字顏色與背景反白色，並確定顏色會正確同步到原始碼與預覽，以便清楚標示重點內容。

### 驗收條件
- [ ] 選取文字後，透過 Quill 工具列的「顏色」選取器可設定文字顏色（`color`）
- [ ] 選取文字後，透過 Quill 工具列的「背景色」選取器可設定文字反白／背景色（`background`）
- [ ] 顏色選取器除常用色票外，支援自訂 Hex 色碼輸入
- [ ] 套用顏色後，左側 `sourceArea` 的 HTML 原始碼同步出現對應 `style="color: ...;"` / `style="background-color: ...;"`
- [ ] 直接在 `sourceArea` 修改顏色相關 style，右側 Quill 需同步更新顯示（既有雙向同步機制涵蓋）
- [ ] `Ctrl+S` 儲存後，顏色樣式正確寫回 `.html` 檔（含同步輸出的 `.md`，非文字樣式的部分可忽略顏色資訊，因 Markdown 不支援行內顏色）
- [ ] 切換至 👁 Preview 模式時，顏色正確渲染於 iframe

### 範圍外（Out of Scope）
- 漸層色、透明度（alpha）調整
- 最近使用色票的持久化儲存（跨檔案/跨 session 記憶）

---

## 子功能 2：建立區塊並設定底色（新功能）

### 使用者故事
- 身為內容編輯者，我希望能在游標處插入一個新的區塊容器，並設定該區塊的背景底色；也希望能對現有段落／選取範圍直接套用背景底色，以便視覺化分隔與強調不同內容區域。

### 驗收條件
- [ ] 工具列新增「插入區塊」按鈕，點擊後在游標所在位置插入一個新的空白區塊容器（如 `<div class="block">`），可在其中輸入/編輯內容
- [ ] 選取既有段落或區塊後，可透過「設定底色」操作（色票 + Hex 輸入）將背景色套用到整個段落／區塊範圍（非僅選取文字的反白色）
- [ ] 底色以 `style="background-color: ...;"` 寫入對應 HTML 元素（區塊容器或段落元素）
- [ ] 底色設定同步反映於左側 `sourceArea` 原始碼與 👁 Preview 預覽
- [ ] 可重新選取已設底色的區塊／段落，變更或清除底色（提供「清除底色」選項）
- [ ] `Ctrl+S` 儲存後，底色樣式正確寫回 `.html` 檔

### 範圍外（Out of Scope）
- 區塊拖曳排序、巢狀區塊、區塊範本庫（屬於 Roadmap Phase 3／4）
- 漸層背景、背景圖片
- 區塊寬度／邊框／圓角等版型樣式（僅聚焦背景顏色）
