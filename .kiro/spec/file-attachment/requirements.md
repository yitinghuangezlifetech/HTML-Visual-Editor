# 需求：檔案附加功能

## 使用者故事
- 身為 HTML 編輯器使用者，我希望能透過上傳方式附加任意檔案，以便將相關資源與 HTML 文件關聯。
- 身為 HTML 編輯器使用者，我希望上傳的檔案自動儲存在與 HTML 檔案同層、同名的資料夾中，以便維持整齊的目錄結構。
- 身為 HTML 編輯器使用者，我希望附加的一般檔案（非 .docx）以連結形式插入 HTML 與 MD 檔案中，以便讀者可點擊存取。
- 身為 HTML 編輯器使用者，我希望附加的 .docx 檔案的文字內容能直接轉換並嵌入 HTML 與 MD 文件中，以便直接閱讀內容而不需額外開啟應用程式。

## 驗收條件

### 一般檔案（非 .docx）
- [ ] 工具列提供「附加檔案」按鈕，點擊後開啟系統檔案選擇對話框
- [ ] 選擇檔案後，在 Extension Host 端於 HTML 同層建立與 HTML 檔名（去除副檔名）同名的資料夾（若已存在則直接使用）
- [ ] 將檔案複製到該資料夾中（同名檔案詢問是否覆蓋或自動加數字後綴）
- [ ] 在 HTML 目前游標位置（或文件末尾）插入相對路徑連結：`<a href="{folder}/{filename}">{filename}</a>`
- [ ] 同步更新 `.md` 檔，插入 Markdown 連結：`[{filename}]({folder}/{filename})`
- [ ] 左側原始碼區域即時反映新增的連結內容
- [ ] 右側 Quill 編輯器即時反映新增的連結內容

### .docx 檔案
- [ ] 選擇 .docx 檔案後，同樣複製到資料夾
- [ ] 使用 `mammoth`（或等效套件）將 .docx 轉換為 HTML 片段
- [ ] 將轉換後的 HTML 內容插入目前游標位置（或文件末尾）
- [ ] 同步更新 `.md` 檔，將 HTML 片段轉換為 Markdown 格式後插入
- [ ] 若轉換失敗，降級為一般連結處理

### 共同條件
- [ ] 上傳過程中顯示狀態訊息（如「正在複製檔案...」「已附加 {filename}」）
- [ ] 若 HTML 檔案尚未儲存（untitled），提示使用者先儲存後再附加

## 範圍外（Out of Scope）
- 不支援多檔案同時上傳（單次選擇一個檔案）
- 不支援拖曳檔案到編輯器附加
- 不支援 .docx 以外的 Office 格式直接嵌入（如 .xlsx、.pptx）
- 不支援圖片預覽（圖片以一般連結處理）
- 不修改已存在的附件連結
