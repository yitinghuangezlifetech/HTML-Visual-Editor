# 需求：面板版面配置（預設 30/70 + 原始碼收闔）

## 使用者故事
- 身為 HTML 編輯器使用者，我希望開啟編輯器時預設以 30% 原始碼、70% 預覽/富文字的比例顯示，以便預覽區域更寬敞。
- 身為 HTML 編輯器使用者，我希望能一鍵完全收闔或展開原始碼面板，以便在純預覽或純編輯時獲得最大空間。

## 驗收條件
- [ ] 開啟編輯器時，左側原始碼面板寬度預設為 30%，右側面板為 70%
- [ ] 工具列提供「收闔原始碼」按鈕，點擊後原始碼面板寬度變為 0（完全隱藏）
- [ ] 工具列提供「展開原始碼」按鈕（或同一按鈕切換），點擊後還原至上次寬度（或預設 30%）
- [ ] 收闔狀態下，原始碼 textarea 不可見、不佔版面空間
- [ ] 展開狀態下，原始碼面板正常顯示且可拖曳調整寬度
- [ ] 收闔/展開狀態在工具列按鈕上有明顯視覺回饋（圖示或文字切換）

## 範圍外（Out of Scope）
- 不儲存收闔狀態至 VS Code 設定（工作階段結束後不保留）
- 不提供右側面板的收闔功能
- 不支援上下分割版面
